Единая подпись письма

Сейчас подпись у каждого своя. Ниже — единый вид по фирменному стилю и готовый блок для каждого сотрудника, логотип уже внутри: копируете и вставляете в настройках своей почты, ничего печатать и вставлять отдельно не нужно.

Как это выглядит

Логотип уже встроен в блок — «Скопировать» переносит его вместе с текстом одним действием.

Как подключить

Один шаг с текстом — логотип уже внутри скопированного блока.

Gmail

  1. Настройки (⚙) → Все настройки
  2. Вкладка «Общие» → блок «Подпись» → «Создать»
  3. Вставьте скопированный блок (Ctrl+V)
  4. Внизу страницы — «Сохранить изменения»

Outlook (веб / Office 365)

  1. Настройки → Почта → Составление и ответ
  2. Раздел «Подписи электронной почты»
  3. Вставьте скопированный блок
  4. «Сохранить»

Outlook (программа на компьютере)

  1. Файл → Параметры → Почта → Подписи
  2. «Создать» (или выберите текущую)
  3. Вставьте блок в поле редактирования
  4. ОК → ОК

Другая почта

  1. Ищите в настройках раздел «Подпись»
  2. Вставьте блок — логотип встанет вместе с текстом

Если кнопка «Скопировать» не сработала — откройте свою карточку ниже, выделите блок подписи вручную и нажмите Ctrl+C. Если после вставки логотип не показался (иногда почта режет встроенные картинки) — во вложении к письму есть файл arko-logo-256.png, его можно добавить кнопкой «изображение» в редакторе подписи.
